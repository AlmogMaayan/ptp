## Arguments

This command takes no arguments.

## Owner

Invoke the `ptp-backlog` skill (`skills/ptp-backlog/SKILL.md`).

## Report

Report the change id where the command resolved one, the resulting state, any failures, and the next command to run. The rendered view shows each entry's ticket title and its GitHub board node id (the `/ptp:backlog-edit` selector) — never a human issue/PR number.
